## 头条｜让 AI 一次只问你一个问题

**Jane Street 的 Socratic Tutor** 是一份给 AI 助手用的教学指令。它先用问题摸底，再根据你的回答安排下一题，最后回顾薄弱环节。想学 Excel、统计或 SQL 时，可以用它做一轮自测，看看自己在哪一步卡住。

**怎么试**　打开项目里的 `socratic-tutor/SKILL.md`，把指令复制到你已有的聊天工具里，再说「用这套方法教我 SQL JOIN。先出一道题摸底，每次只问一题」。支持 Skills 的助手也可以按仓库说明安装。

**为什么关注**　雷达快照记录该仓库 **8,706 星**，比上一份快照多 **341 星**。这是一项 GitHub 关注度信号。另用 Jane Street 仓库的 README 核对了教学方式和使用入口。 [Jane Street 官方仓库](https://github.com/janestreet/agent_skills)

## 值得试｜DeepSeek 官方静态聊天界面

**DeepSeek Chat Demo** 提供一个浏览器里的聊天界面，支持对话分支、Markdown、附件和聊天记录导出。已有 DeepSeek API Key、想试独立界面的读者，可以用它跑一段测试对话。

**怎么试**　从官方仓库 README 点在线演示，或者从 Releases 下载静态页面。先在 Settings 填入自己的 DeepSeek API Key，再用一段非敏感的测试文本试试编辑消息、切换分支和导出。官方说明称对话历史保存在浏览器，发送内容时会提交给所配置的 API 服务。

**为什么关注**　雷达快照记录该仓库 **1,917 星**，比上一份快照多 **730 星**。另用 DeepSeek 官方 README 核对了功能、体验入口和 API Key 要求。 [DeepSeek 官方仓库](https://github.com/deepseek-ai/chat-demo)
